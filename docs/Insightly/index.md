
# **Insightly** - The Most Important Variables

Group project that I am currently participating in.

**Overview**

"The Most Important Variables" is an universal application for analyzing the most important features in datasets.

**Key Features**

- Data Loading: The user can upload a CSV/JSON file or use a ready-made sample dataset.
- Automatic Recognition: An LLM model detects column names and assigns appropriate descriptions.
- Target Column Selection: The user selects the column for analysis or uses automatic detection (generated by the LLM).
- Intelligent Analysis: The application automatically identifies whether the data relates to a regression or classification problem and selects the appropriate AI model training algorithm.
- Results Visualization: Based on the trained model, a chart displaying the most important features is presented.
- Recommendations: The user receives a clear description of the chart along with actionable recommendations to improve results.

**Built With**

- Large Language Model (LLM) for data interpretation
- AI algorithms for regression and classification
- Data visualization libraries (e.g., Plotly, Matplotlib)
- CSV/JSON file handling
